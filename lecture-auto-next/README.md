# 📻 강의 자동 넘김 (Chrome 확장 프로그램)

크롬에서 강의 영상을 보다가 **영상이 끝나면 다음 회차로 자동 이동**하고,
**마지막 회차가 끝나면 1회차부터 다시 반복**합니다. 라디오처럼 틀어두기만 하면 됩니다.

## 설치 방법

1. 이 저장소를 내려받습니다 (Code → Download ZIP 후 압축 해제).
2. 크롬 주소창에 `chrome://extensions` 입력.
3. 오른쪽 위 **개발자 모드** 켜기.
4. **압축해제된 확장 프로그램을 로드합니다** → `lecture-auto-next` 폴더 선택.
5. 툴바의 퍼즐 아이콘에서 📌 고정하면 편합니다.

## 사용 방법

### 방법 A. '다음' 버튼 클릭 방식 (기본)
1. 강의 **1회차 페이지**를 엽니다.
2. 확장 아이콘 클릭 → **현재 페이지를 1회차로 지정**.
3. 영상을 재생하면 끝! 영상이 끝날 때마다 `다음 차시`, `다음 강의`, `Next` 같은 버튼을 자동으로 찾아 클릭합니다.
4. 마지막 회차에서 '다음' 버튼이 없으면 1회차로 돌아가 다시 재생합니다.

> 버튼을 못 찾는다면: 다음 버튼에서 우클릭 → **검사** → 해당 요소의 class/id를 확인해
> `다음 버튼 CSS 선택자` 칸에 `.btn_next` 또는 `#nextBtn` 형태로 입력하세요.

### 방법 B. URL 회차 번호 방식
강의 주소가 `...?lecture=1`, `...?lecture=2` 처럼 번호만 바뀌는 사이트라면:
- 이동 방식을 **URL의 회차 번호 바꾸기**로 선택
- URL 패턴: `https://사이트주소/view?lecture={n}` (01, 02 형태면 `{nn}`)
- 시작 회차 / 마지막 회차 입력 → 저장

마지막 회차 다음에는 시작 회차로 돌아갑니다.

## 기타 옵션
| 옵션 | 설명 |
|---|---|
| 넘기기 전 대기(초) | 영상 종료 후 다음으로 넘어가기까지 기다리는 시간 |
| 재생 속도 | 모든 강의 영상에 배속 적용 |
| 자동 재생 | 페이지가 열리면 영상을 자동 재생 |
| 확인창 자동 확인 | "다음 차시로 이동하시겠습니까?" 같은 팝업을 자동으로 '확인' |
| 지금 다음으로 ▶▶ | 설정이 맞는지 바로 테스트 |

## 자동 재생이 음소거로 되는 경우
크롬은 사용자가 클릭하지 않은 페이지에서 **소리 있는 자동 재생을 막습니다.**
이때 확장은 음소거로라도 재생을 이어갑니다. 소리까지 자동으로 나오게 하려면
크롬을 아래 옵션으로 실행하세요.

- **Windows**: 크롬 바로가기 우클릭 → 속성 → 대상 끝에 한 칸 띄우고 추가
  ```
  --autoplay-policy=no-user-gesture-required
  ```
- **Mac**: 터미널에서
  ```
  open -a "Google Chrome" --args --autoplay-policy=no-user-gesture-required
  ```
(실행 중인 크롬 창을 모두 닫고 다시 열어야 적용됩니다.)
