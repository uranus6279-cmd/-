# ⬇️ 영상 다운로더 (Chrome 확장 프로그램)

웹페이지에서 재생되는 **영상/음성 파일을 자동으로 찾아** 목록으로 보여주고, 클릭 한 번으로 내려받습니다.
**m3u8(HLS) 스트리밍 영상**은 조각들을 모두 받아 **하나의 파일로 합쳐서** 저장합니다.

## 설치 방법

1. 이 저장소를 내려받습니다 (Code → Download ZIP 후 압축 해제, 또는 `video-downloader.zip`).
2. 크롬 주소창에 `chrome://extensions` 입력.
3. 오른쪽 위 **개발자 모드** 켜기.
4. **압축해제된 확장 프로그램을 로드합니다** → `video-downloader` 폴더 선택.
5. 툴바의 퍼즐 아이콘에서 📌 고정하면 편합니다.

## 사용 방법

1. 영상이 있는 페이지에서 영상을 **재생**합니다.
2. 아이콘에 빨간 숫자(찾은 개수)가 뜨면 아이콘을 클릭합니다.
3. 목록에서 원하는 항목의 **다운로드**를 누릅니다. 큰 파일이 위에 오므로 보통 맨 위가 본 영상입니다.

| 항목 종류 | 버튼 | 동작 |
|---|---|---|
| mp4, webm, mp3 등 일반 파일 | 다운로드 | 바로 저장 |
| m3u8 (HLS) | 합쳐서 받기 | 새 탭에서 화질 선택 → 조각을 모두 받아 한 파일로 저장 |
| mpd (DASH) | 목록 파일 받기 | 목록 파일만 저장 (합치려면 ffmpeg 필요) |

- 각 항목 아래에 **진행률 / ✅ 완료 / ❌ 실패 원인**이 표시됩니다. 팝업을 닫았다 열어도 남아 있습니다.
- **저장할 위치 매번 묻기**를 켜면 저장 대화상자가 뜹니다.
- **주소 복사**로 원본 주소를 복사해 다른 프로그램에서 쓸 수 있습니다.

## m3u8(HLS) 합쳐서 받기

- 여러 화질이 있으면 고를 수 있습니다 (기본: 가장 높은 화질).
- 결과 파일은 `.ts` 또는 `.mp4`입니다. `.ts`는 VLC, 팟플레이어 등에서 바로 재생됩니다.
  mp4로 바꾸고 싶다면: `ffmpeg -i 영상.ts -c copy 영상.mp4`
- 받는 동안 진행률이 표시되며, **그 탭을 닫으면 중단**됩니다.
- 받은 조각은 메모리가 아니라 브라우저 임시 파일에 차례로 쓰므로 수 GB 영상도 메모리를 거의 쓰지 않습니다
  (4GB 영상 기준 약 0.6GB). 대신 영상 크기의 약 2배만큼 디스크 여유 공간이 잠시 필요합니다.
- 목록에 m3u8이 여러 개 보이면 **맨 위 항목**을 고르세요. 플레이어가 가장 먼저 받은 전체 목록(화질+음성 정보)입니다.

### 이런 경우도 처리합니다
| 상황 | 처리 |
|---|---|
| 서버가 가끔 오류(500)를 내거나 연결이 끊김 | 최대 3번 다시 시도 |
| 조각 하나가 응답 없이 멈춤 | 20초 동안 데이터가 없으면 다시 시도 |
| 핫링크 차단(Referer 검사) | 원래 페이지 주소를 붙여 요청. 일반 mp4가 403으로 막히면 자동으로 다시 시도 |
| 로그인 쿠키가 필요한 사이트 | 브라우저 쿠키를 그대로 사용 |
| 주소나 형식을 숨긴 재생목록 (`/api/play?id=7`, text/plain) | 응답 내용(`#EXTM3U`)으로 찾아냄 |
| 조각을 이미지(.jpg/.png)로 위장 | 가짜 머리를 잘라내고 영상 부분만 사용 |
| 한 파일을 바이트 범위로 나눈 재생목록 | 필요한 범위만 요청 |
| 영상과 음성이 따로 오는 재생목록 | 영상/음성 **두 파일**로 저장 (합치는 ffmpeg 명령 안내) |

## 실패하면 원인을 알려줍니다

다운로드가 실패하면 팝업의 해당 항목에 **❌ 실패 원인**이 빨간 글씨로 표시됩니다. 예:

| 표시 | 뜻 / 해결 방법 |
|---|---|
| 파일이 없습니다(404)… (전체 30개 중 11번째 조각) | 주소가 만료됨 → 페이지 새로고침 후 영상을 다시 재생하고 시도 |
| 서버가 접근을 거부했습니다(403) | 주소 만료 또는 사이트가 외부 다운로드를 막음 |
| 로그인이 필요합니다(401) | 사이트에 로그인 후 다시 시도 |
| 서버가 20초 동안 응답하지 않았습니다 | 서버가 멈춤 (3번 다시 시도한 뒤에도 실패) |
| 암호화된 스트림이라 받을 수 없습니다 | DRM/암호화 영상 (지원 안 함) |
| 실시간(라이브) 방송은 지원하지 않습니다 | 방송이 끝난 다시보기에서 시도 |
| 디스크 공간이 부족합니다 | 저장 공간 확보 후 다시 시도 |

## 지원하지 않는 것

- **YouTube**: 크롬 웹스토어 정책상 YouTube 다운로드 기능은 허용되지 않으며, 영상이 화질별·음성별로
  잘게 나뉜 서명된 주소로 전송되어 그대로 받아도 재생 가능한 파일이 되지 않습니다.
  오프라인 시청은 YouTube Premium의 '오프라인 저장' 기능을 이용하세요.
- **암호화/DRM 스트림** (넷플릭스, 유료 VOD 등) 및 `#EXT-X-KEY`가 걸린 m3u8.
- **실시간(라이브) 방송** m3u8. 방송이 끝난 뒤 다시보기에서 시도하세요.
- `blob:` 주소로만 재생되는 영상은 실제 파일 주소(대개 m3u8)가 네트워크에서 잡힐 때만 받을 수 있습니다.
- **DASH(.mpd)** 영상은 목록 파일만 받을 수 있습니다.
- 플레이어가 **자바스크립트로 특별한 인증 헤더**를 붙여야 받을 수 있는 사이트 (403 원인이 표시됩니다).
- 영상/음성이 따로 오는 경우 **한 파일로 합치지는 못합니다** (두 파일로 저장).

## 테스트

`../video-downloader-tests`에 실제 사이트의 까다로운 동작 26가지를 흉내 낸 테스트가 있습니다
(불안정한 서버, 핫링크 차단, 위장 조각, 1.5GB 대용량 등). 실행 방법은 그 폴더의 README를 보세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 (Manifest V3) |
| `background.js` | 네트워크 응답을 보고 미디어를 찾아 탭별로 기록, 다운로드 실행과 상태 기록 |
| `content.js` | 페이지의 `<video>`/`<audio>` 태그에서 재생 주소 수집 |
| `main-world.js` | 주소/형식을 숨긴 m3u8을 응답 내용으로 찾아냄 |
| `popup.html` / `popup.js` | 찾은 영상 목록, 다운로드 버튼, 진행률/실패 원인 표시 |
| `hls.html` / `hls.js` | m3u8 조각을 받아 한 파일로 합치는 페이지 (403으로 막힌 일반 파일 재시도도 담당) |
| `reasons.js` | 실패 코드를 이해하기 쉬운 문장으로 바꿈 |

> 본인이 권리를 가졌거나 다운로드가 허용된 콘텐츠에만 사용하세요.
